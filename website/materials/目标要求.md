# P0-2｜目标岗位或晋升标准

先选一个近期目标。没有正式 JD 或晋升标准也可以开始，请保留“暂定”标记。

## 最少必填

- 本轮场景：求职 / 晋升
- 当前职业、工作年限或资历：
- 目标职位或目标级别：
- 正式标准是否已有：有 / 暂无 / 只有自己的理解
- 最想证明的一项能力（不确定可写未知）：

## 如果是求职

首轮优先给一份最想投的真实 JD；有多份时说明公司、岗位、日期或来源，同一岗位转载可标“重复”。暂无 JD 时先写目标，不能据此推造岗位要求。

- 目标岗位 JD 的相关原文或链接（可粘贴核心要求）：
- 目标工作内容与业务环境：
- 对方最可能关心的 2–3 项能力（注明来自 JD 还是个人猜测）：
- 我希望突出或解释的经历：

## 如果是晋升

- 当前级别与目标级别（可用代称）：
- 组织标准的相关原文/评价条目，或写暂无：
- 评审者主要关注什么？注明来自正式标准 / 反馈 / 个人理解：
- 我已经承担的责任与影响范围：
- 我认为还缺什么（不确定可留空）：

## 输出使用限制（有就写）

- 字数、时长、版式或组织模板：
- 希望使用的现有方法/框架：
- 截止时间：
