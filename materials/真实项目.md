# P0-1｜一个真实项目的原始资料

不用润色。先写最近或最有代表性的一项经历，不知道就写“不知道”。没有完成的项目也可以，但请说明当前阶段。

## 最少必填

- 项目名称（可用代称）：
- 项目时间（大致即可）：
- 我的职业、资历与项目角色：
- 当时为什么做这个项目？服务谁、解决什么问题？
- 我本人具体做了什么？请列 2–5 项真实动作：
- 目前有什么结果、交付或反馈？没有记录可写未知：
- 我以前如何介绍它？粘贴原句即可：

## 有就补充，没有留空

- 目标或验收标准：
- 团队其他人负责什么？谁有决定权？
- 最难的问题或限制（时间、资源、权限、技术等）：
- 关键选择：选了什么；考虑过什么其他方案；为什么没选？
- 我的权限：我决定 / 我建议后获批 / 我执行 / 我协助（说明具体事项）：
- 做得不理想的部分与原因：
- 下次会继续采用或改变的做法：
- 可提供的资料位置（对应证据目录即可）：
